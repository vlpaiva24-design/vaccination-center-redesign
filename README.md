# Novotek Vaccination Center — redesign

Интерактивный прототип нового интерфейса системы управления центром вакцинации.

## Демо

[Открыть приложение на GitHub Pages](https://vlpaiva24-design.github.io/vaccination-center-redesign/)

## Что реализовано

- обзор рабочего дня;
- календарь и список приёмов;
- создание приёма и пациента;
- база пациентов и паспорт вакцинации;
- предвакцинальный осмотр;
- отчёты и справочник вакцин;
- настройки клиники;
- адаптивная версия для планшетов и телефонов.

Все демонстрационные персональные данные вымышлены.

## Запуск

```bash
npm install
npm run dev
```
